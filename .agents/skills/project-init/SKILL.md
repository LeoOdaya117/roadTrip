# Initialize RoadTrip project knowledge

Use when asked to initialize project knowledge or refresh the architecture map.

1. Read `AGENTS.md`, architecture/convention/testing guides, and existing `.codex/knowledge/` files. Inspect manifests, routes, entry points, integrations, persistence, and test/build configuration.
2. Create or refresh `.codex/knowledge/PROJECT_CONTEXT.md` with verified stack, boundaries, flows, entry points, commands, and known platform limits. Label uncertain inferences.
3. Update `.codex/knowledge/PROJECT_NOTES.md` only with conventions verified from source or canonical docs. Preserve useful notes and explain corrections to stale facts.
4. Append to `.codex/knowledge/DECISIONS.md` only for a meaningful decision established during initialization. Do not store secrets, environment values, or personal data.
5. Do not edit product code, tests, plans, or generated output. Summarize files updated and unresolved items.
